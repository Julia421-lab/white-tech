# WhiteTech transfer prototype

Clickable prototype of the WhiteTech B2B money transfer flow (Recipient → Amount → Review → Confirm → Result).

Single file, no build step: open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 5188
```

Use the **Prototype controls** panel (bottom-left) to jump to any screen, restart the prototype,
auto-approve the in-app confirmation, or make the bank reject the next payment.
Demo SMS code: `123456`.
